# Avaliação de roteamento

Foram executados dez cenários independentes: um acionamento positivo e um near-miss para cada uma das cinco skills. Todos os resultados utilizaram exclusivamente nomes canônicos.

O cenário sem fonte oficial recomendou a skill de curadoria condicionada ao fornecimento da fonte em `dados_necessarios`; nenhuma curadoria definitiva foi simulada. O cenário ambíguo permaneceu no acompanhamento e pediu apenas o objetivo discriminante.

## Ampliação proposta em 2026-09-24

O catálogo passou a incluir três cenários ainda sem execução comportamental: invocação nominal do treinador externo disponível, pedido genérico de questão FGV/ENAM no plugin e invocação nominal quando a habilidade externa está ausente. O primeiro registra `expected_external_skill`, sem `expected_route`; os demais preservam os cinco destinos internos canônicos. A invocação positiva deve ser testada no cliente que instala ambas as skills; não é uma sexta rota do plugin. Os dez cenários históricos acima permanecem como resultado da avaliação anterior, sem extrapolação para os três novos.
