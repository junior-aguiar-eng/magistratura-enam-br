# Avaliação de roteamento

Foram executados dez cenários independentes: um acionamento positivo e um near-miss para cada uma das cinco skills. Todos os resultados utilizaram exclusivamente nomes canônicos.

O cenário sem fonte oficial recomendou a skill de curadoria condicionada ao fornecimento da fonte em `dados_necessarios`; nenhuma curadoria definitiva foi simulada. O cenário ambíguo permaneceu no acompanhamento e pediu apenas o objetivo discriminante.
